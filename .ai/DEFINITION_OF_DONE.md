# Definition of Done

Uma mudança está concluída quando:
- Critérios de aceite estão satisfeitos.
- Arquitetura/guardrails foram respeitados.
- Testes relevantes existem e passam.
- Erros e timeouts são tratados.
- Logs não expõem segredos.
- Novas permissões estão documentadas.
- Contratos foram versionados quando necessário.
- Documentação foi atualizada.
- Não existem TODOs críticos ocultos.
- O fluxo principal pode ser demonstrado de ponta a ponta no ambiente previsto.
