# Antigravity / AI Implementation Guide — Delivery 07

Leia primeiro `.ai/BOOTSTRAP.md` e os guardrails existentes. Implemente uma capability por vez. Não substitua o Core por um framework de agentes autônomos. Não permita chamadas diretas entre agentes. Use ports/adapters para STT, TTS, LLM, vector store e pesquisa. Todo conteúdo externo é não confiável. Não crie memória implícita sem política de retenção e proveniência. Teste contratos antes de integrações reais.
