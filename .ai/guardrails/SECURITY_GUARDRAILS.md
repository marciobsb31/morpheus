# Security Guardrails

Default deny. Menor privilégio. Segredos em secret store. Ações de risco alto exigem aprovação explícita. Entradas externas são não confiáveis. Prompt injection é tratado como dado hostil. Câmera/microfone têm indicadores e consentimento. Auditoria não registra conteúdo sensível desnecessário.
