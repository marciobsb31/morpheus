# Definition of Done — Agent

Um agente só pode ser marcado `ready` quando:
- [ ] missão e limites estão documentados;
- [ ] manifesto possui ID/versionamento válidos;
- [ ] capabilities têm schemas, risco e efeitos definidos;
- [ ] permissões seguem menor privilégio;
- [ ] eventos e API estão versionados;
- [ ] erros/retry/idempotência estão definidos;
- [ ] observabilidade não vaza segredos;
- [ ] threat model específico foi revisado;
- [ ] testes obrigatórios passam;
- [ ] integração com Registry + Policy Engine foi validada;
- [ ] documentação e changelog foram atualizados.
