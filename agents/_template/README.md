# <agent-name>

Resumo humano do agente. Substitua todos os placeholders antes de registrar o agente.

- **ID:** `morpheus.agent.<domain>.<name>`
- **Owner lógico:** `<domain>`
- **Runtime:** `<java|python|powershell|other>`
- **Execution zone:** `<local|cloud|hybrid>`
- **Status:** `proposed`

## Quick start
1. Leia `AGENT.md`.
2. Declare capacidades em `CAPABILITIES.md`.
3. Declare ferramentas e integrações em `TOOLS.md`.
4. Classifique permissões em `PERMISSIONS.md`.
5. Defina eventos em `EVENTS.md`.
6. Implemente os testes de `TEST_PLAN.md`.
7. Só marque `ready` quando o checklist de `DEFINITION_OF_DONE.md` estiver completo.
