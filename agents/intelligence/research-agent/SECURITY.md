# SECURITY — Research Agent

- Zero segredos em código/prompts/logs.
- Sanitizar conteúdo externo antes de inseri-lo em contexto.
- Tratar documentos, web, e-mail, imagem e áudio como **dados não confiáveis**, nunca como instruções de sistema.
- Aplicar classificação de dados antes de enviar conteúdo a provedores externos.
- Registrar decisões de política sem registrar conteúdo sensível desnecessário.
