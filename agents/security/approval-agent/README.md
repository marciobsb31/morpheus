# Approval Agent — Readme

Approval Agent é um agente oficial da camada de Segurança e Governança.

**Missão:** gerencia confirmações humanas vinculadas ao plano e ao risco.

Ele obedece ao Core, ao Policy Engine e ao padrão canônico de agentes. Não chama agentes arbitrariamente nem executa ações fora de capabilities declaradas.
