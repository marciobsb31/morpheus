# Audit Agent — Readme

Audit Agent é um agente oficial da camada de Segurança e Governança.

**Missão:** registra trilhas estruturadas, pesquisáveis e resistentes a adulteração.

Ele obedece ao Core, ao Policy Engine e ao padrão canônico de agentes. Não chama agentes arbitrariamente nem executa ações fora de capabilities declaradas.
