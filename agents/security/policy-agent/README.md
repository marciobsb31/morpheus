# Policy Agent — Readme

Policy Agent é um agente oficial da camada de Segurança e Governança.

**Missão:** avalia policy-as-code e produz allow/deny/require-approval com justificativa.

Ele obedece ao Core, ao Policy Engine e ao padrão canônico de agentes. Não chama agentes arbitrariamente nem executa ações fora de capabilities declaradas.
