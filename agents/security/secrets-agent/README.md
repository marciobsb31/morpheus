# Secrets Agent — Readme

Secrets Agent é um agente oficial da camada de Segurança e Governança.

**Missão:** intermedeia referências a segredos sem expor valores ao LLM ou agentes indevidos.

Ele obedece ao Core, ao Policy Engine e ao padrão canônico de agentes. Não chama agentes arbitrariamente nem executa ações fora de capabilities declaradas.
