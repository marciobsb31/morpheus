# Security Agent — Readme

Security Agent é um agente oficial da camada de Segurança e Governança.

**Missão:** coordena postura de segurança, avalia sinais e consolida decisões de proteção.

Ele obedece ao Core, ao Policy Engine e ao padrão canônico de agentes. Não chama agentes arbitrariamente nem executa ações fora de capabilities declaradas.
