# Trust Agent — Readme

Trust Agent é um agente oficial da camada de Segurança e Governança.

**Missão:** calcula sinais de confiança de dispositivos, plugins e sessões sem substituir autorização.

Ele obedece ao Core, ao Policy Engine e ao padrão canônico de agentes. Não chama agentes arbitrariamente nem executa ações fora de capabilities declaradas.
