# ADR-0001 — Desenvolvimento AI-First

**Status:** Accepted

## Contexto
Múltiplas IAs de desenvolvimento poderão contribuir com o Morpheus. Memória conversacional não é uma fonte confiável e compartilhada.

## Decisão
O repositório será a fonte de verdade. `.ai/` conterá instruções normativas e ADRs registrarão decisões estruturais.

## Consequências
Há custo de documentação, mas reduz deriva arquitetural, retrabalho e inconsistência entre ferramentas.
