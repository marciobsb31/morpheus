# ADR-0012-vue-tauri-desktop — Vue 3 + Tauri para Desktop

**Status:** Aceito

## Contexto
O Morpheus precisa permanecer coerente ao ser desenvolvido por múltiplas IAs e ferramentas.

## Decisão
Interface desktop em Vue 3/TypeScript com Tauri 2, mantendo renderer sem privilégios diretos.

## Consequências
A decisão reduz deriva arquitetural. Exceções futuras precisam de evidência e novo ADR.
