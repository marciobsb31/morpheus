# ADR-0014-github-actions-ci — GitHub Actions para CI/CD

**Status:** Aceito

## Contexto
O Morpheus precisa permanecer coerente ao ser desenvolvido por múltiplas IAs e ferramentas.

## Decisão
Usar GitHub Actions como pipeline inicial, com possibilidade de adapter/migração futura.

## Consequências
A decisão reduz deriva arquitetural. Exceções futuras precisam de evidência e novo ADR.
