# Memory Model

## Camadas
1. Working memory: duração da tarefa/sessão.
2. Episodic history: eventos resumidos e auditáveis com retenção.
3. Semantic memory: fatos/preferências autorizados com proveniência.
4. Knowledge stores: documentos/coleções, separados de memória pessoal.

Cada registro deve possuir ID, tipo, conteúdo/embedding quando aplicável, origem, confiança, createdAt, lastUsedAt, retenção, classificação, owner e escopo. Deve existir atualização, expiração e esquecimento verificável.
