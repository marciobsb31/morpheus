# Proactive Assistance Model

Proatividade no Morpheus significa **detectar, sugerir e pedir autorização quando necessário**, não executar qualquer ação arbitrária.

Níveis:
1. `OBSERVE`: detectar reunião/prazo.
2. `SUGGEST`: apresentar recomendação.
3. `PREPARE`: montar rascunho/plano reversível.
4. `EXECUTE_LOW_RISK`: somente ações previamente autorizadas por política.
5. `REQUEST_APPROVAL`: mutações ou ações sensíveis.

Quiet hours, cooldown, deduplicação e relevância devem impedir excesso de alertas.
