# Entrega 07 — Inteligência, Voz e Memória

## Objetivo
Criar a especificação da camada cognitiva do Morpheus sem transformar o LLM em autoridade de execução. O Core continua soberano sobre planejamento, políticas e execução.

## Componentes
Voice, STT, TTS, LLM Gateway, Memory, Context, Knowledge/RAG, Research e Vision.

## Princípios
Local-first para dados sensíveis; cloud sob política; provider abstraction; memória com proveniência e esquecimento; conteúdo externo é dado não confiável; respostas estruturadas; observabilidade sem vazar conteúdo.
