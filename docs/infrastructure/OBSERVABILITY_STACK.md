# Observability Stack

OpenTelemetry instrumenta traces, métricas e logs correlacionados. Prometheus coleta métricas; Grafana exibe dashboards; Loki centraliza logs. Alertas mínimos: Core indisponível, filas crescendo, DLQ, falha de banco, latência P95, erro de provider de IA, falha de backup e repetidas negações de segurança.
