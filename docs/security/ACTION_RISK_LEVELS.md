# Níveis de Risco de Ações

- **R0 — leitura pública/local inofensiva:** status de CPU, hora, agenda já autorizada.
- **R1 — reversível:** abrir app, ajustar volume, mostrar notificação.
- **R2 — efeito externo/relevante:** enviar mensagem, alterar compromisso, controlar dispositivo físico.
- **R3 — destrutiva/privilegiada:** excluir dados, instalar software, desligar infraestrutura, executar como administrador.

A política pode permitir R0/R1 automaticamente. R2 depende de contexto e configuração. R3 exige confirmação explícita por padrão e trilha de auditoria reforçada.
