# Defesa contra Prompt Injection

Conteúdo de e-mail, web, documentos, OCR, notas e mensagens é dado não confiável, nunca instrução de sistema. Ferramentas são autorizadas fora do LLM. O modelo não pode ampliar suas permissões. Instruções embutidas em conteúdo são tratadas como texto e não podem desativar políticas.
