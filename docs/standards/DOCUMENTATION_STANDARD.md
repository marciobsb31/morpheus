# Padrão de Documentação

Todo módulo futuro deve possuir README com propósito, fronteiras, dependências, como executar e testar. Agentes terão ainda `AGENT.md`, `CAPABILITIES.md`, `EVENTS.md`, `PERMISSIONS.md`, `TOOLS.md`, `TEST_PLAN.md`, `BACKLOG.md` e `CHANGELOG.md`.

Documentos normativos usam linguagem explícita: MUST/DEVE, SHOULD/DEVERIA, MAY/PODE quando útil.
