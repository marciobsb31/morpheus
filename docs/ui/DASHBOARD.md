# Dashboard / Command Center

Tela principal do Morpheus. Centro: Morpheus Core Orb com estado e resposta atual. Esquerda: saúde do PC, serviços, agentes e ambiente de desenvolvimento. Direita: agenda, tarefas, alertas e casa. Rodapé: command bar por texto/voz.

Cards são contextuais. Em modo Trabalho, priorizar agenda, IDE, Docker e tarefas; em Casa, clima, luzes, mídia e cenas.
