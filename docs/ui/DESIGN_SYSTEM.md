# Design System

Visual dark premium, inspirado em centro de comando futurista sem copiar interfaces cinematográficas. Base neutra escura, superfícies translúcidas moderadas, tipografia legível e acentos luminosos controlados.

## Tokens semânticos
`surface`, `surface-elevated`, `text-primary`, `text-muted`, `accent`, `success`, `warning`, `danger`, `focus`.

Componentes: AppShell, NavRail, CommandBar, CoreOrb, StatusChip, MetricCard, Timeline, AgentCard, DeviceCard, ApprovalDialog, Toast, Drawer e DataTable.
