# Fluxos Principais

## Preparar ambiente
Comando → transcrição → intenção → plano → execução → progresso → confirmação.

## Aprovação sensível
Intenção → policy detecta risco → ApprovalDialog → usuário aprova → token de aprovação limitado → execução → auditoria.

## Reunião próxima
Evento Calendar → notificação/HUD → usuário aceita preparar ambiente → workflow coordenado pelo Core.
